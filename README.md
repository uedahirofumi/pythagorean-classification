# Pythagorean Classification Project

## Status
**Canonical snapshot:** 2026-10-07 v1

This repository records the classification of completely multiplicative functions additive on primitive Pythagorean triples.

Main proved nondegenerate classification:

> Let F:N→C be completely multiplicative, F(1)=1, and satisfy F(a)+F(b)=F(c) for every primitive Pythagorean triple a^2+b^2=c^2. If F(2) and F(3) are not both zero, then F is either F(n)=n^2 or one of 12 explicitly identified Dirichlet characters.

Corollary:
F(2)F(3)F(5)F(13) != 0  =>  F(n)=n^2 for all n.
